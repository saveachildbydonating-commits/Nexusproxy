GOOD TO KNOW

Questions, answered.

What is NexusProxy?

A starter platform for managing proxy-service subscriptions. Real proxy traffic requires a separate infrastructure provider integration.

How do payments work?

Card checkout uses Stripe scaffolding. Crypto checkout uses Coinbase Commerce scaffolding. Configure provider credentials and verified webhooks before accepting live payments.

Are these proxy endpoints live?

No. This project provides the subscription storefront, account features, and payment integration scaffolding. It does not create proxy endpoints or guarantee uptime.

Can I cancel a subscription?

This starter records a 30-day access period after confirmed Stripe payment. Recurring billing and cancellation workflows must be added before production launch.
